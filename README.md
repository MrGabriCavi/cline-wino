# ClineWin

A native Windows version of Cline Desktop, an AI coding assistant.

It is built with WinUI 3 and .NET 10, and the interface is in Italian.

## Build and run

```powershell
dotnet build -p:Platform=x64
dotnet run -p:Platform=x64 --no-build
```

You need Windows 10 or 11 and the .NET 10 SDK.
